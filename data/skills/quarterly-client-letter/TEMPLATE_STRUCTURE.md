# Quarterly Client Letter — Template Structure

## Standard Sections

### 1. Header
- Fund name and reporting period
- "Dear Investor" salutation

### 2. Performance Summary
| Metric | QTD | YTD | 1-Year | Since Inception |
|--------|-----|-----|--------|----------------|
| Fund Return | | | | |
| Benchmark Return | | | | |
| Relative Performance | | | | |

### 3. Market Commentary
- 3-4 sentences on key market developments during the quarter
- How market conditions affected the fund's strategy

### 4. Portfolio Highlights
- Top 5 contributors and detractors (with brief rationale for each)
- Any significant portfolio changes during the quarter

### 5. Sector Allocation
| Sector | Portfolio Weight | Benchmark Weight | Active Weight |
|--------|-----------------|-----------------|---------------|
| [Sector] | X.X% | X.X% | +/-X.X% |

### 6. Outlook
- 2-3 sentences on positioning for the coming quarter
- Key themes and conviction level

### 7. Sign-off
- Portfolio Manager name and title
- Contact information
